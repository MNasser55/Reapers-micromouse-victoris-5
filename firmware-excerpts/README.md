# Competition-Derived Firmware Excerpts

These files are cleaned excerpts adapted from the firmware used by Team Reapers during IEEE Victoris 5.0.

They preserve the real engineering approach while intentionally omitting:

- the complete run supervisor and integration layer,
- production pin assignments and device addresses,
- final PID, PWM, threshold, and calibration values,
- full hardware initialization,
- and enough surrounding code to build a drop-in competition image.

The excerpts are educational and are not a standalone PlatformIO project.
